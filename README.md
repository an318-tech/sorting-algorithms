# Алгоритмы и структуры данных — домашнее задание

## Файлы
- `sort_algorithms.py` — пузырьковая сортировка, сортировка выбором и вставками + бенчмарк и график.

## Запуск
```bash
python sort_algorithms.py
```
Скрипт проверяет корректность алгоритмов на тестовом списке, замеряет время
на случайных списках разных размеров и сохраняет график `benchmark.png`.

## Алгоритмы
| Алгоритм | Сложность (лучший/худший случай) | Память |
|---|---|---|
| Пузырьком | O(n) / O(n²) | O(1) |
| Выбором | O(n²) / O(n²) | O(1) |
| Вставками | O(n) / O(n²) | O(1) |
